## 🔎 최종 상승 초입 관찰 가이드 (`T-131`)

3개년·1개년·2026년 YTD 백필 비교 결과, 거래량 5배 급등을 추격하던 기존 `상승초입 3일 이내`는 손절률이 높고 기대수익률·손익비가 가장 낮아 **폐기**했습니다. 대신 수동 MTS 매매 시 시장 국면과 취향에 맞춰 즉시 참조할 수 있도록 **최종 상승 초입** 두 가지 상호보완 트랙(각 최대 5종목)과 실전 참조 가격선을 제공합니다.

1. **상승 초입 · 20일 돌파 확정 (`early_inception`)**
   - **조건:** 추세·대금(`Close ≥ SMA20`, `SMA20/60 정배열`, 20일 거래대금 중앙값 `≥ 5억`) + 비과열(`60일 모멘텀 ≤ 25%`, `SMA60 이격 ≤ 1.18`) + 20일 변동성 수축(`변동폭 ≤ 25%`, `수축비 ≤ 0.85`) + **직전 20일 고점 종가 돌파(`Close ≥ prior_h20`)** + 수급 점화(`5일 거래량비 ≥ 1.20x` 또는 `당일 ≥ 1.35x`, `CMF20 ≥ -0.05`).
   - **특징:** 20일 박스권 상단을 이미 종가로 돌파한 정석 후보로, 단기(5거래일 내) `+5%` 도달 탄력이 가장 빠릅니다.
2. **상승 초입 · 20일 수축 돌파임박 (`early_contraction`)**
   - **조건:** 동일한 추세·대금·비과열·수급 점화 조건 위에서 **더 타이트한 20일 수축(`수축비 ≤ 0.65`)**을 형성한 채 **직전 20일 고점 `-3.0%` 이내(`0.97 × prior_h20 ≤ Close < prior_h20`)**에 바짝 붙어 있는 돌파 직전 후보입니다.
   - **특징:** 돌파 확정 표에 종목이 뜨지 않는 지수 눌림·숨고르기 구간에서도 선제적 거래량이 유입된 길목 종목을 포착하며, 다기간 백필에서 기대수익률·손익비가 가장 높고 `-5%` 손절 도달률이 가장 낮았습니다.
3. **MTS 참조 가격선 안내**
   - **20일 기준고점 (돌파이격):** 직전 20거래일 최고가(돌파 기준선)와 현재 종가의 괴리율입니다.
   - **참조 손절 / 추세선:** 평가일 종가 대비 `-5%` 보호 손절 기준가 및 단기 추세 약화 기준선인 `SMA10`(10일 이동평균선)입니다.
   - 다음 날 시초가 갭이나 장중 체결 여부는 일봉 관찰에 반영되지 않으며, 전진 관찰의 가상 성과 평가는 20거래일 확보 후 추세 약화 청산 엔진(`SMA10` 이탈·고점 대비 `-6%` 트레일링·`-5%` 손절)으로 독립 집계됩니다.

`backlog.json`은 직접 수정하지 않고 반드시 CLI 도구를 사용합니다:

```bash
# 1. 지금 바로 착수 가능한 작업 확인
node tools/backlog.mjs next

# 2. 작업 착수 (코드 수정 전 필수!)
node tools/backlog.mjs set <id> in_progress

# 3. 작업 완료 처리
node tools/backlog.mjs set <id> done

# 4. 판단/대기 상태 기록 (사유 필수)
node tools/backlog.mjs set <id> needs_decision --note "결정 필요 사유"

# 5. 작업 통계 및 무결성 검증
node tools/backlog.mjs stats
node tools/backlog.mjs check
```

## 📊 PostgreSQL & Grafana 모니터링 대시보드

백로그 현황을 시각화하고 진행 이력을 추적할 수 있는 하이브리드 대시보드 환경입니다.

### 1. 인프라 실행 (Docker Desktop 실행 후)
```bash
cd infra/monitoring
docker compose up -d
```
- **Grafana 웹 접속**: `http://localhost:3000` (ID: `admin` / PW: `admin`)
- 사전 구성된 **Leobox Multi-root Backlog Overview** 대시보드가 자동 로드됩니다.

### 2. 백로그 데이터베이스 동기화
```bash
# 백로그 변경 후 DB에 즉시 반영
node tools/backlog.mjs sync-db
```
