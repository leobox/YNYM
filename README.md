## 🔎 상승초입 3일 이내 관찰 가이드

**상승 초입**은 기본 관찰 목록, **상승초입 3일 이내**는 압축돌파·거래량폭발을 보는 별도 집중 관찰 목록입니다. 각 엔진이 독립적으로 최대 5개를 선별하므로 두 목록이 항상 포함 관계인 것은 아닙니다. 기본 표의 딱지는 같은 평가일의 3일 목록에 실제로 포함되는지를 표시합니다.

3일 엔진은 완료 일봉에서 직전 20일 고점 돌파, 20·60일 이동평균 이상, 윗꼬리 비율 ≤ 40%, 60일 이격도 ≤ 1.18, 모멘텀 ≤ 25%, CMF20 ≥ −0.05 및 거래대금 조건을 확인합니다. 이후 다음 두 경로 중 하나를 충족해야 합니다.

- **압축돌파:** 수축비 ≤ 0.45, 그리고 5일 거래량 비율 ≥ 1.2 또는 당일 거래량 배수 ≥ 1.35.
- **거래량폭발:** 수축비 ≤ 0.70, 그리고 당일 거래량 배수 ≥ 5.0.

다음 날 시초가 갭이나 장중 흐름은 이 일봉 선별·딱지에 반영되지 않습니다. ‘3일’은 집중 관찰 전략의 이름이며, 3일 내 수익을 보장하거나 자동으로 진입·청산하는 뜻이 아닙니다. 현재 전진 관찰의 결과 평가는 20거래일 확보 후 기존 가상 청산 엔진으로 계산합니다. 짧은 과거 표본의 도달률을 미래 확률로 제시하지 않습니다.

## 📋 백로그 관리 (CLI 기반 SSOT)

`backlog.json`은 직접 수정하지 않고 반드시 CLI 도구를 사용합니다:

```bash
# 1. 지금 바로 착수 가능한 작업 확인
node tools/backlog.mjs next

# 2. 작업 착수 (코드 수정 전 필수!)
node tools/backlog.mjs set <id> in_progress

# 3. 작업 완료 처리
node tools/backlog.mjs set <id> done

# 4. 판단/대기 상태 기록 (사유 필수)
node tools/backlog.mjs set <id> needs_decision --note "결정 필요 사유"

# 5. 작업 통계 및 무결성 검증
node tools/backlog.mjs stats
node tools/backlog.mjs check
```
