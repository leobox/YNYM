`backlog.mjs set <id> done` 실행 시 자동 비동기 음성 안내가 트리거되도록 연동.
또한 멀티 에이전트 공통 규칙(`AGENTS.md`) 및 `GEMINI.md`에 골든 룰로 등재하여 지속적으로 음성 안내를 수행하도록 정립.
