## 🔎 감사 결과 요약 (재설계 근거, 직접 재실행한 값)
- **검증-운영 불일치**: T-046은 일봉, 운영 `run_vcp_scanner.py`는 Yahoo 60분봉에 일봉용 rolling 창을 적용. 운영 그대로 60분봉 백테스트: 신호 791건, 같은 시각 무작위 종목 대비 12백분위, 계좌 mp=1 -61.5% / mp=3 -29.8%.
- **T-046 "흑자 전환"은 우연 범위**: 필터 통과 104건 승률 30.8% < 무필터 32.7%(손익분기 ≈36%). 무작위 104건 부분집합 300회 대비 mp=1 87백분위, mp=3 58백분위. 후반부 승률 19.6%. 통계표에서 유의한 변수는 `bull_aligned`(p=0.004)뿐인데 백테스트 필터에 없었고, VCP 수축비는 방향이 반대.
- **일봉 재설계 시 약한 가능성**: 일봉(정배열+60일 돌파+거래량+과열 제한), VCP 수축 제거 → 같은 시각 무작위 종목 대비 99백분위, 건당 +0.75%(부트스트랩 95% CI -0.35~+1.86, 0 포함). VCP 수축 조건을 넣으면 오히려 악화.
- 한계: 임계값을 정한 것과 같은 구간(새 OOS 아님), 고정 종목군 생존편향, 표본 작음, 다중 변형 비교.
