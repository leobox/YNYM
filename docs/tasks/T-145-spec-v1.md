## 1. 목적과 운영 제약

장 마감 완료 일봉으로 섹터 상대강도 개선을 관찰하고, 사람이 다음 날 한 번 확인하여 진입·보유·청산 판단에 활용한다. 바닥 예측, 검증되지 않은 상승 확률, 거래대금을 자금 순유입으로 표시하는 기능은 넣지 않는다. 프로그램 주문·계좌 연동·실시간 감시는 없다.

역사 연구 E0와 실제 확인 기록 E1을 분리한다. E0 성과로 E1 실현 성과를 주장하지 않는다. 실제 사용자의 계좌 금액·확인 시각·증권사 예약 기능은 연구 가정으로 대신 확정하지 않는다.

RS는 분배금 포함 총수익, 실제 체결·수량은 당시 거래가격으로 구분한다. 추세·ATR용 OHLC 조정과 체결가격 환산은 기업행사 시점까지 포함해 일관성을 검증한다. 공급원의 `AdjClose`라는 필드명만으로 총수익 정합성이 입증된 것은 아니다.

당시 상장/상폐·분류·구성표·분배금·기업행사·공급원·조회시각·원본 해시를 입력 manifest로 보존한다. 현재 대표를 과거 전체에 적용한 결과는 탐색용이며 편향 없는 검증으로 표시하지 않는다. 구성종목 동조화는 PIT 자료가 있을 때 보조 표시하며 **50%/70%/80% 필수 게이트는 없다**.

## 3. 관찰·진입 자격·선발

완료일 t의 ETF 총수익 지수를 P, 해당 지역 벤치마크를 B라고 한다. 기간은 거래일이다.

```text
RS20(t) = (P(t) / P(t-20)) / (B(t) / B(t-20)) - 1
개선(t) = RS20(t) - RS20(t-5)

관찰 = RS20(t) > 0 AND 개선(t) > 0
신규 자격 = 관찰 AND 종가 > SMA60
                    AND 종가 - SMA20 <= 2 * ATR20
```

- ATR20은 Wilder 방식으로 계산한다. SMA는 해당 완료일까지의 단순이동평균이다. 실제 구현 시 조정 가격·원가격 변환과 prefix 불변성을 검증한다.
- 최근10거래일 안에 RS20이 0 이하에서 양수로 전환하면 `최근 상대강도 전환`, 이전부터 양수면 `강세 지속`으로 표기한다. 이는 미래 상승 초입 판정이 아니다. 강세 지속을 이유로 탈락시키지 않는다.
- 매일 관찰·청산 판단. **신규 편입은 매주 마지막 거래일 마감1회**, 빈 슬롯만 검토한다.
- 자격 내 RS20 내림차순, 동률 대표 코드 오름차순. 최대3개 섹터, 무후보 허용. 지역별 자격·레짐을 먼저 평가하고 지역 벤치마크 대비 RS20으로 최종 선발한다.
- 동일 섹터 중복 보유·보유 중 반복 진입 금지. 순위 변동만으로 보유를 교체하지 않는다.
- 60일 수익률25%/35% 상한, RS10/40 교차, +10% 이후 별도 청산 모드 등의 과거 제안은 채택하지 않는다.

## 4. ETF와 개별주 비교

- **B 주 실험**: 선택된 섹터의 대표 ETF.
- **C 병렬 비교**: 같은 섹터의 당시 구성종목 중20일 거래대금 중앙값 상위5개에서, 섹터 대표 대비 RS20이 가장 높고 양수인1종목. SMA60·2ATR 이격 자격 적용. 동률 거래대금, 그다음 코드 순.
- C의 해외 구성/PIT 자료가 없으면 해당 지역 C는 미실시로 표시한다. 국내 결과를 해외에 전용하지 않는다.
- B/C의 실제 노출·현금·변동성·0주 탈락률을 함께 보고한다. C가 B보다 낫다는 증거가 없으면 C를 승격하지 않는다. B 역시 자체 검증을 통과해야 한다.
- A-legacy는 기존 개별주 전략의 버전별 제품 비교다. 섹터 게이트의 순수 효과는 새 C와 **동일 개별주 우주·점수·일정·청산·수량**에서 섹터 게이트만 제거한 A-matched를 별도로 비교한다. 여러 조건을 바꾼 차이를 섹터 하나의 효과로 주장하지 않는다.

## 5. 자금·위험 예산

| 항목 | 확정 값 |
|---|---:|
| 역사 연구 초기 계좌 | 30,000,000원 |
| 소액 실행 별도 시나리오 | 1,000,000원 |
| 최대 동시 보유 | 3슬롯 |
| 신규 수량 산정 시 슬롯당 명목 비중 상한 | 계좌자산25% |
| 2ATR 기준 슬롯당 명목 위험 예산 | **계좌자산0.5%** |

```text
q_target = floor(min(NAV_t * 0.25 / 기준가격,
                     NAV_t * 0.005 / (2 * 진입 전 ATR20)))
```

- E0의 기준가격은 신호일 종가다. 후보·수량·비용 포함 예산을 전날 현금으로 확정한다. 현금 제약에 맞게 수량을 줄이는 절차도 그 시점에 끝낸다. **다음 시가를 미리 보고 예약 수량을 최적화하지 않는다.**
- 다음 시가의 실제 가상 매입원가가 사전 예산을 넘으면 해당 주문은 미체결. 사후 종목 대체 금지. 이 예산 제한은 불명확한 시가전용 지정가를 가정하는 것과 구분한다.
- 25%/75%는 신규 수량 산정 상한이며 항상 달성할 목표가 아니다. 갭·보유 중 가격 변동으로 평가 비중이 달라질 수 있다. 비중 유지를 위한 자동 리밸런싱은 없다.
- 정수 수량0은 미진입으로 기록한다. 3,000만원에서도0주가 가능하다. B/C/단순 기준에 같은 위험 산식을 적용한다.
- **1.5% 위험 예산 제안은 철회됐다.** 0.5%는 갭·지연·비용까지 포함한 최대 손실 보장이 아니다.

## 6. 실행 모델

### E0 — 역사 연구의 기본 가상 체결

- 전날 확정한 후보·수량·예산으로 다음 정규장 시가 가상 체결. 상방·하방 갭 모두 원가격에 반영한다. 비용/예산 초과·무거래·거래중단·결측은 별도 상태다.
- **미확인 시가전용 상한 및 장중 SMA20 가격 필터는 없다.** 일봉 Low 접촉 손절/익절도 없다.
- 신호/수량 선정에 다음 날 최종 고저·거래량을 사용하지 않는다. 선정 이후 무거래 자료를 체결로 확정하지 않는다. Volume>0은 시가 전량 체결의 증명이 아니다.
- 시가 유동성·부분 체결을 완전히 복원하지 못하는 **연구 근사**임을 표시한다. 거래정지/늦은 첫 거래를 정상09시 체결로 위장하지 않는다. 결측일을 조용히 건너뛰어 유리한 다음 가격으로 채우지 않는다.
- 매도대금·현금 재사용 시점, 동시 주문 우선순위, 비용·호가 단위는 구현 명세에 봉인한다. 청산한 봉의 재진입과 같은 시각 청산 예정 대금의 선사용은 금지한다. 부족 예산을 차입으로 메우지 않는다.
- 시가 근사 성과는 실제 사용자 수동 실행 성과가 아니다.

### E1 — 실제 수동 확인 및 전진 저널

- 사용자가 실제 한 번 확인한 시각·가격을 기록한다. 비교용11:00 KST는 연구 기준이며 사용자 확정 시각이 아니다.
- 신규 확인 가격이 `전일 SMA20 < 확인 가격 <= 전일 종가 + 0.5×ATR20`이면 진입 검토한다. 범위 밖·누락·미확인은 무거래. 예정 확인1회에서 미진입하면 신호 취소, 임의 장중 소급 체결 금지.
- 확인/주문/체결 시각·실제 수량·가격·미체결·수수료를 분리한다. 주문하지 않은 신호는 가상 관찰로 표시한다.
- 첫12주 저널은 실행·수집·보존 정합성을 점검한다. 12주로 수익성 확정을 주장하지 않는다.
- 일봉 지표 워밍업에는 일봉을 사용한다. 앞6개월까지 분봉을 요구하는30개월 분봉 필수 논증은 철회됐다. 시각 자료가 있어도 실제 조회·체결 지연과 구분한다.

### M1 — 예약 상한 주문

**본선 제외·보류.** 증권사별 주문 유효기간·잔량·자동취소·집행시장·실패 처리를 확인하기 전 `Open>상한 → 당일 미체결` 또는 `Open<=상한 → 전량 체결`을 실제1:1 재현으로 사용하지 않는다. E0/E1 완성을 기다리게 하는 전제조건이 아니다.

## 7. 보유·청산·시장 레짐

매일 완료 종가로 다음 중 하나라도 충족하면 청산 대기한다.

1. 2일 연속 종가<SMA20.
2. 종가<진입가−2×진입 전 ATR20.
3. 해당 지역 벤치마크 종가<SMA120.

E0는 다음 정규장 시가 가상 청산, E1은 다음 실제 수동 확인/체결 가격으로 기록한다. 판정선에서 체결된 것으로 고정하지 않으며 갭 손실을 그대로 반영한다. 기업행사 때 진입가·수량·ATR 단위를 일관되게 조정한다.

지역 벤치마크 종가≥SMA120일 때만 해당 지역 신규 진입을 허용한다. 미달 지역은 현금 유지, 다른 지역은 해당 벤치마크로 독립 판정한다. 약세장 독주 섹터 예외나 금·달러·인버스 자동 전환은 없다. 약세장에도 전체 관찰과 RS 전환 기록을 유지한다.

고정+5%/+10% 익절,20일 강제 만기는 없다. 순위 하락·높은 이격만으로 보유를 청산하지 않는다. 평가기간 말 미청산 포지션은 평가손익으로 남기며 거래 수를 늘리기 위한 임의 종가 청산을 하지 않는다.

## 8. 비용·원장·재현

- 원장 키에 `spec_version`, `candidate_engine_sha256`, `exit_engine_sha256`, `universe_manifest_sha256`, 매핑/가격/비용 모델 해시를 보존한다. 과거 후보를 현재 청산 함수로 재평가한 것은 별도 재분석으로 분리한다.
- 같은 비용 계산 규칙을 적용하되 상품·기간·계좌별 세금/수수료 차이는 반영한다. 주식0.18%를 모든 연도에 고정하거나 ETF에 주식 거래세를 복사하지 않는다. 운용보수 이중 차감 금지.
- 실제 계좌/과표/비용 자료가 없으면 명시적인 연구 시나리오로 기록하고 실제 세후 성과라고 하지 않는다. 비용 값·기간별 세율표는 성과 열람 전에 자료 manifest에 봉인한다.
- 현금/잔고/정수 수량/배당/기업행사/실현·평가손익을 구분하고 회계 보존식을 검증한다. 원본·미체결·실패·무후보를 보존한다. 성과가 끝나기 전에 신호를 삭제하지 않는다.

### 공통 전제

- 미래정보 prefix 불변성, 원본/종목군/PIT/가격 조정, 체결과 비용, 현금 회계를 먼저 통과해야 한다.
- 미사용 검증기간≥24개월, 종료된 포지션 에피소드≥60개. 보유 중 반복 신호는 별도 거래로 세지 않는다. 최소 기준이며 독립성/통계 충분성의 보장은 아니다.
- 이미 본 데이터는 연구 진단용으로 활용할 수 있지만 새 OOS로 부르지 않는다. 자료 부족이 구현·역사 진단·전진 기록 착수를 금지하는 것은 아니다.

### B의 주 비교군

같은 ETF군에서 **단순60일 수익률 상위3개**를 선택하는 기준. RS/개선/이격 게이트를 제외하고 자료 자격·레짐·편입 주기·실행 모델·수량·청산·비용 규칙을 공통 적용한다. 별도로 지역 시장 보유·균등 보유·A/C를 보고한다. 서로 다른 노출을 사후 확대해 맞추지 않는다.

### 채택 증거 문턱

| 항목 | 기준 |
|---|---|
| 비용 후 계좌 수익 | 양수 |
| 단순60일 기준 대비 연율 수익 차이 | ≥+2.0%p |
| 일별 순수익 차이 신뢰구간 | 20거래일 이동블록 bootstrap10,000회, seed20261107, 양측95% 하한>0 |
| 최대낙폭 | 일별 종가 평가 MDD≤15% |
| Profit Factor | 종료 거래 총순이익/총순손실 절댓값≥1.2. 총손실0이면 미정의·판정 유보 |
| 비용 스트레스 | 비용2배에서 비용 후 수익과 단순 기준 대비 차이 모두 양수 |

거래별 수익을 독립 표본처럼 bootstrap하지 않는다. 랜덤 정책에 실제 전략의 사후 보유기간/퇴출일을 복사하지 않는다. 비용 스트레스와 지연은 각각 평가하며 실제 법정 세율 변경이나 실제 체결 증거로 표시하지 않는다.

승률 최소50% 같은 추가 문턱은 없다. 승률·평균 이익/손실·손실 꼬리·보유기간·월 거래 수·회전율·현금·집중도·노출·0주 탈락·미체결·열린 포지션을 함께 보고한다. 연율 수익은 전체 검증기간·동일 계좌 기준으로 산출하고 짧은 기간 연율화를 기대수익으로 홍보하지 않는다.

### 결과 분기

- 자료와 최소 표본을 충족한 상태에서 경제성/위험 기준 실패: **해당 v1.0 기각**.
- 추정 개선은 양수이나 신뢰구간에0 포함: **우위 미입증**.
- 원본/PIT/비용/기간/실행 자료 부족: **검증 부족**.
- 모두 통과: **해당 실행 모델·검증 범위에서 채택 검토 가능**. E0만 통과했다면 E1 수동 운영 검증 완료로 승격하지 않는다.
- C가 B보다 낫다는 증거가 없으면 C 보류. B도 자체 기준 미달이면 B 역시 승격 금지. 특정 명세의 실패를 모든 섹터 가설의 영구 부정으로 확대하지 않는다.
- 결과를 본 뒤 값 변경·기간 재선택·후보 추가는 새 시도다. 전체 시도 수를 기록하고 별도 최종 구간/다중검정 보정을 요구한다.

## 10. 구현 착수 시 고정할 실행 입력과 인수인계

규칙 토론은 종료한다. 후속 담당자는 성과를 열기 전에 아래 실행 입력을 데이터 가용성에 맞춰 파일로 봉인한다. 이는 새 숫자 튜닝 허가가 아니다.

- 정확한 대표 ETF/지역 벤치마크/섹터 구성표와 유효기간, 과거 상장/상폐 자료.
- 실제 데이터 기간·휴장 달력·가격/분배금 조정·조회시각·실패 상태·해시.
- 계좌 시나리오별 날짜/상품 비용표, 비용·지연·무작위 실행 manifest.
- 사전 현금 예산 배분·동시 주문 우선순위·부분 체결 근사·무거래/정지/결측 처리의 결정적 구현 명세와 테스트.
- 후보·청산·계좌 엔진 버전, 검증 구간, 시도 등록부. 원자료가 없으면 그 검증은 미실시로 남긴다.

T-145 완료는 **이 사양의 동결 및 인수인계 완료**다. 자료 확보, 전략 구현, 백테스트, 실제 수동 기록, 운영 적용은 후속 작업이며 이번 완료에 포함하지 않는다.
