# T-096: 동적 EPS·RAG 탐색 결과의 선행 시점 봉인 저널

- **상태**: done
- **담당**: Codex
- **선행 작업**: T-092
- **소유 파일**: `quant-research/research/forward_decision_journal.py`, `quant-research/tests/test_forward_decision_journal.py`, 이 문서

## 목적

Gemini의 T-095 판정 작업과 파일을 분리한다. 기존 모드 2 `explore`의 최신 완료 일봉 판정과 EPS 원본을 **수집 당시의 입력 해시**와 함께 불변 JSON으로 보존한다. 향후 가격이 충분히 쌓이면 이 봉인된 선행 관측만 결과 평가에 사용한다. T-094 전년 동기 EPS 증감을 표준화 SUE나 검증된 알파로 승격하지 않는다.

## 계약

1. `--capture` 없이 실행하면 쓰기 없는 준비 상태 점검만 한다. 평가일은 `daily-plan`이 택한 **마지막 저장 일봉**으로 고정하며 날짜를 과거로 지정할 수 없다.
2. 한국 시간 오늘과 같은 날짜의 일봉은 완료 증빙이 없어 봉인을 거부한다. 평가일이 미래이거나 3달력일 넘게 오래되어도 거부한다. 금요일 종가는 월요일까지 허용하는 운영 신선도 기준이다. 이것은 SUE 감쇄 파라미터가 아니다.
3. 보유 종목 가격이 불완전하거나 가격 CSV 원본이 없으면 봉인을 거부한다. 결측을 0이나 직전 가격으로 대체하지 않는다.
4. 가격 CSV 전부, EPS 스냅샷, 가상 상태, RAG 종목명 자료, 관련 코드의 SHA-256 및 일일 판정 내용을 기록한다. 소스 해시를 판정 전후에 비교하고, 그 사이 값이 바뀌면 봉인을 거부한다. 입력과 판정이 같으면 같은 `run_id`를 만들고 기존 파일을 재사용한다. 다른 입력은 새 파일이 된다. 완성된 임시 파일을 독점 하드링크로 설치해 기존 기록을 덮어쓰지 않는다.
5. 저널은 실제 주문도 가상 체결도 실행하지 않으며, EPS 가산점을 넣지 않는다. T-095의 판정 로직을 수정하지 않는다.

## 실행

```powershell
# 준비 상태 확인 (쓰기 없음)
python -B quant-research/research/forward_decision_journal.py

# 신선한 완료 일봉이 있을 때만 불변 기록 생성
python -B quant-research/research/forward_decision_journal.py --capture
```

기본 출력은 `quant-research/data/research/T-096/runs/<run_id>.json`이다. 원본 가격·EPS 파일은 이 저널에 복사하지 않으므로 재현 시 SHA-256이 일치하는 원본이 별도로 필요하다.
