## 📝 작업 기록
- 2026-09-18: 작업 생성. 배경: `quant-collector`에서 RSI를 Wilder 표준으로 재검증하다가
  ([[T-034]] 참고) ATR도 같은 문제(단순이동평균 근사)가 있음을 발견 → 사용자가 "먼저
  quant-research 쪽 기존 프레임워크부터 살펴보자"고 지시. `quant-research/research/`
  (`walk_forward.py`, `account_simulator.py`, `signal_generator.py`, `bias_reporter.py`)와
  `scanner/`(`pattern.py`, `data_adapter.py`, `indicators.py`)를 조사한 결과:
  - `scanner/pattern.py`의 `hourly_pattern`은 `quant-collector/collector.py`의 동일 함수와
    로직이 완전히 같다(포팅 관계 확인). `indicators.py`의 `_atr`도 collector.py의 폐기 전
    버전과 동일한 단순이동평균 근사였다.
  - `research/account_simulator.py`는 이미 다음봉 시가 진입, 편도 수수료 0.175%, 단일
    포지션(동시 보유 제한), 동일봉 손절우선 처리, MDD/스킵신호/미체결 집계를 갖춘 훨씬
    엄밀한 체결 시뮬레이터였다 — 오늘 quant-collector에서 스크래치패드로 급조한 백테스트
    (수수료 0, 신호봉 종가 즉시체결, 동시보유 무제한 가정)보다 훨씬 현실적이다.
  - `research/walk_forward.py`는 train/validate/test 구간 분리 + 구간 겹침(data leakage)
    자동 검출 + `bias_reporter`의 생존편향/상폐누락/15시구간누락 경고를 매 리포트에 자동
    첨부한다. `tests/test_prefix_invariance.py`로 lookahead bias도 정식 검증한다.
  - 결론: 오늘 quant-collector에서 낸 모든 백테스트 결론(T-030/T-033/vol_squeeze/
    운영전략 SMA-vs-Wilder 비교)은 "방향성 빠른 판단"용이었지 이 프로젝트의 정식 검증
    기준에는 못 미친다. 정식 검증은 quant-research의 기존 프레임워크로 다시 해야 한다.
- 2026-09-18: `indicators.py`의 `_atr`을 Wilder's smoothing(ewm alpha=1/period)으로 교체.
  `tests/` 52건 전체 통과(prefix invariance 포함), 회귀 없음.
