## 🔒 §6 · §10에 따라 코드에 봉인한 세부 집행 명세

1. **사전 현금 예산 배분 (`allocate_precommitted_entry_budgets`)**:
   - 신호일(`t`) 마감에 정산 현금(`unreserved_cash`) 범위 안에서 우선순위(`RS20` 내림차순, 코드 오름차순)대로 `q`를 먼저 감축해 `sum(base_cost_i) <= unreserved_cash`를 확정한다(`Open_{t+1}` 미열람).
   - 현금 여유가 충분할 때는 KRX 일일 가격제한폭 상한(`1.30 * base_cost_i`)까지 주문별 사전 예산을 배정하여, `E0`가 미확인 시가전용 지정가(`M1`)처럼 상방 갭을 인위적으로 회피하지 않고 상방·하방 갭을 모두 원가격(`Open`)으로 수용하게 한다.
   - 현금이 `sum(1.30 * base_cost_i)`보다 적을 때는 잉여 현금을 `base_cost_i` 비율로 결정론적 배분하여 `sum(reserved_budget_i) <= unreserved_cash`를 보장하며, 익일 시가 매입 유출액이 `reserved_budget_i`를 넘으면 차입이나 사후 수량 재조정·종목 대체 없이 `BUDGET_EXCEEDED_AT_OPEN` 미체결로 기록한다.
2. **슬롯 점유·청산 예정 대금 선사용 금지·동일 봉 재진입 금지**:
   - 청산 대기(`PendingExitOrder`) 상태인 포지션은 실제 시가 청산 체결이 끝날 때까지 슬롯을 계속 점유한다(`len(open_positions) + len(pending_entries) <= 3`). 따라서 청산 예정일에 거래정지가 발생해도 3슬롯을 초과하지 않으며, 청산 예정 대금을 선사용해 신규 주문을 낼 수 없다.
   - 같은 날 아침(`t` Open) 청산 체결로 유입된 현금은 `same_morning_exit_inflow` 에스크로에 분리 보관했다가 같은 시각 매수 체결 검사가 모두 끝난 뒤 현금 원장에 합산한다.
   - `t` Open에 청산된 `(region, sector)` 및 `code`는 같은 봉(`t` Close) 주간 선발에서 즉시 제외한다(`청산한 봉의 재진입 금지`).
3. **무거래·거래정지·결측 비대칭 처리**:
   - 신규 진입 예정일 시가에 결측/`Halted`/`Volume <= 0`이면 해당 날짜에 `UNFILLED_HALTED_OR_NO_TRADE_AT_OPEN`으로 취소하며 다음 거래일 가격으로 이월 체결하지 않는다.
   - 보유 포지션 청산 예정일 시가에 결측/`Halted`/`Volume <= 0`이면 `EXIT_DELAYED_HALT_OR_NO_TRADE`를 기록하고 거래 재개 첫 유효 시가에 청산한다(`exit_delay_halts` 집계).
4. **기업행사·회계 보존식·보유 중 SMA20 연속 이탈 카운트**:
   - 분할/병합 시 보유 수량·단주 현금(`cash_in_lieu`)·진입 기준가·진입 전 `ATR20`을 동일 배율로 조정하고, 배당락일 현금배당을 현금 원장에 계상하며 매일 `cash + MTM == initial_capital + realized_price_pnl_cum + dividends_cum + unrealized_pnl` 보존식을 오차 `1e-5`원 이내로 강제 검증한다.
   - `2일 연속 종가 < SMA20` 카운터(`below_sma20_streak`)는 체결 시점에 `0`으로 초기화하고 진입일 완료 종가부터 누적한다.
   - 평가 종료일(`eval_end`)에 열린 포지션은 강제 종가 청산하지 않고 `open_positions_at_end` 및 일별 평가자산(MTM)으로 보존한다.
