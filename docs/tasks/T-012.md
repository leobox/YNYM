## 📝 구현 내용
- `tools/backlog.mjs`:
  - 스키마 필드 추가(모두 optional): `log`, `owner`, `claimed_at`, `parent`, `gate`, `done_when`.
  - `validate()`: deps 완료 게이트(status≠todo면 deps 전부 done 필요), `parent` 참조/자기참조 검사.
  - `save()`: 순환 의존성 탐지(`findDependencyCycle`, DFS 3색), 쓰기 전 `backlog.json.bak` 백업.
  - `cmdSet`: `--expected-status`(선택, 불일치 시 거부), `done` 전환 시 `--note` 필수(이 커맨드
    호출에 실제로 `--note`가 있어야 함 — 과거의 stale note로는 통과 안 됨), `gate` 있는 작업은
    `--ack-gate` 없이 `done` 불가, `--owner`, `claimed_at` 최초 `in_progress` 시 자동 기록, 매 전환마다
    `log`에 `{at, status, note}` append.
  - `cmdAdd`: `--done-when`, `--gate`, `--parent`, `--deps` 옵션 추가(이전엔 `--deps` 자체가 없어서
    생성 시 선행 작업을 지정할 방법이 없었음 — 실제 버그였음).
  - `cmdUpdate` 신설: 기존에 선언만 되고 안 쓰이던 `EDITABLE` 상수를 실제로 연결(status/id/log는
    변경 불가, `set` 전용).
- `tools/ai/check_syntax.cjs`(신규): 저장소 전체 `.js`/`.cjs`/`.mjs`에 `node --check` 실행.
  `tools/ai/lifecycle.cjs`의 Stop 단계 `checks` 배열에 추가 — Claude/Codex/Gemini 공통 적용.
  라인 길이 검사는 이식하지 않음(`quant-collector/collector.py` 738줄 등 기존 정상 파일이 300줄
  기준에 걸려 즉시 막히므로).
- `docs/ai-setup.md`, `CLAUDE.md`: 새 옵션과 Stop 단계 구문검사 반영.
