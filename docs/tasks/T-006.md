## 한계와 후속 작업

- 각 AI 클라이언트 안의 자동 이벤트 발생·신뢰 상태는 미검증. Codex는 새 세션의
  `/hooks`에서 신뢰 상태를 확인해야 한다. 신뢰 우회나 사용자 전역 설정 변경은 하지 않았다.
- Gemini CLI는 PATH에 없다. Antigravity가 Gemini CLI 훅을 읽는다고 가정하지 않는다.
- 훅은 알려진 호출/문법/타임아웃의 보조 검사이며 실제 거래 금지, 전략·데이터·회계
  정확성의 완전한 검증 수단이 아니다. 기능 구현·재현은 T-007 등 별도 작업이다.
- 저장소는 아직 최초 커밋 전이므로 기존 HEAD와의 diff는 불가능하다.
  커밋·푸시·외부 배포는 수행하지 않았다.
