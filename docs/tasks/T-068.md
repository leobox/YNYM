## 목적과 사전 고정 방식

기존 60분봉 운영 코드를 바꾸지 않고, 5분 원본 한 벌을 기준으로 5·10·30·60분봉을 직접 집계해 같은 역사 구간에서 확인했다. 결과를 보고 신호 임계값을 튜닝하지 않았다. 2026-09-20 시점의 `universe_20260920_1257.csv` 150종목을 고정했다. 이 종목군은 현재 기준 선정이라 과거 종목군 생존편향이 있다.

- Yahoo Finance 비공식 chart API `range=60d, interval=5m`, 수정주가 미적용. 2026-09-22 22:08 KST 부근 수집. 149종목 성공, `415640.KS` HTTP 422로 제외. 수집 manifest에는 종목별 행 수·기간·SHA256·실패 사유와 종목군 SHA256을 기록했다. 로컬 5분 원본은 `raw_5m/`에 보존하고 Git에는 넣지 않는다. 재수집은 새 `--out` 경로를 요구한다.
- `09:00~14:55`의 5분봉 72개가 모두 있는 종목·날짜만 사용. Yahoo의 15:00 표시 행은 제외한다. **15:00~15:30 거래와 공식 종가는 이 데이터에 없다.** 각 간격은 동일한 완료 5분봉에서 OHLCV를 합친다.
- 기존 `confirmed_breakout`의 12/26봉 이동평균, 3봉 기울기, 직전 6봉 고가 돌파, 양봉·봉 내 종가 위치 ≥0.7, 4 ATR 이격 제한, 직전 같은 시간 슬롯 20표본 중앙값 대비 거래대금 ≥2배, 다음 봉 유지 조건을 적용한다. 거래대금 절대 하한 60분당 10억원을 봉 길이에 비례해 5/10/30분에 축소했다. **봉 개수 기준 lookback은 그대로**이므로 간격마다 실제 관찰 시간이 달라지며 직접적인 우열 비교에는 한계가 있다.
- 신호봉 종료 후 다음 관측 5분봉 시가에 가상 진입한다. 장 마지막 봉은 다음 거래일 09시 시가를 쓴다. 5분봉의 고저로 +10% 익절/−5% 손절/최대 5거래일을 판정한다. 동시 접촉은 손절 우선, 갭 손절은 시가, 목표 위 갭은 목표가. 진입·청산 각각 수수료 0.175%와 슬리피지 0.05%를 적용한다. 같은 종목은 이전 가상 결과가 종료될 때까지 후속 신호를 세지 않는다. **계좌 수익률이 아니라 종목별 비중복 신호의 건당 결과**다.
- 마지막 20거래일(2026-08-26~09-22)을 평가 대상으로 지정했고, 5일 결과가 없는 마지막 4거래일 신호는 검열했다. 실제 평가 가능 신호일은 2026-08-26~09-16, 16거래일이다.

## 원본 교차 확인과 한계

새 5분 원본에서 합친 60분봉을 변경되지 않은 기존 연구 스냅샷 `quant-research/data/live_60d_20260918`과 대조했다. 겹치는 99종목 32,622봉에서 OHLC 가격은 모두 일치했다. 거래량만 1,235봉에서 달랐으며, 기존 시간봉의 월요일 09시 거래량 0 기록이 주된 원인이다. T-067이 동시에 수정 중인 `quant-collector/data/bars_history`는 비교 기준으로 사용하지 않았다. 네 간격 비교는 모두 **같은 새 5분 원본**만 사용했다. 원본은 비공식 공급원이고 수정주가·기업행사·상폐 종목·당시 종목군을 보정하지 않았다.

```powershell
python quant-research/scripts/validate_multi_interval.py evaluate
python -m pytest quant-research/tests -q
python tools/ai/quant_guard.py
node tools/backlog.mjs check
```
