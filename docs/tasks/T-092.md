## 적용된 가상 운영 규칙

- `daily-plan`은 마지막으로 완료된 일봉 종가까지의 자료로 다음 관측 거래일의 후보 계획을 생성한다. 실제 주문·계좌 API 없음.
- 매일 브레드스<40%면 전량 청산 계획. 방어 후 브레드스≥50%가 2거래일 지속되면 재진입 가능. 20거래일 정기 점검에는 상위 10위 잔류 종목 HOLD, 탈락 종목 SELL, 빈 슬롯의 상위 후보 진입을 계획한다.
- 보유 종목 순위>30 또는 종가<SMA120이면 정기 점검 전이라도 다음 거래일 청산 계획. 현재 봉 저가가 −15% 스톱 아래면 별도 검토 신호를 낸다. 정기 점검 시 보유 종목의 종가 평가 비중이 25%를 넘으면 가상 감축 계획을 낸다.
- 10% 슬롯 예산으로 정수 1주도 살 수 없는 후보는 `SKIP`한다. 같은 시가에 매도한 대금은 같은 시가의 매수에 재사용하지 않는다.
- `daily-plan --apply --date <신호일>`은 다음 날 완료 일봉이 저장된 경우에만 시가 가상 체결 및 당일 저가 스톱을 상태 파일에 반영한다. 동일 신호 적용은 멱등적이다. 상태가 갖고 있는 종목의 봉이 없으면 가상 체결을 막는다.
- 기존 월간 `rebalance --apply`도 다음 거래일 완료봉이 없을 때 당일 시가에 소급 체결하지 못하도록 차단했다.
