### 2. `LRM-60 v2.0` 가상 계좌 21건 해부 및 365종목 60분봉 백테스트
- `lrm60_state.json`의 21건 거래 중 `STOP_TOUCH`가 12건이며, 그중 **5건(41.7%)이 진입과 동일한 60분봉(`entry_ts == exit_ts`)에서 즉시 손절**됨.
- 원인: `stop = max(entry * 0.96, breakout_level * 0.99)`에서 진입가가 돌파선 근처에 형성될 때 손절 폭이 `1.27% ~ 2.21%`로 극단적으로 좁아져 통상적인 60분봉 아래꼬리에 즉시 접촉함.
- 365개 종목 60분봉(`2026-06-25` ~ `2026-10-16`, 독립 체결 176건) 백테스트 결과:
  - 구조적 손절 버퍼 확대(`min(entry * 0.975, breakout_level * 0.99)` 또는 `breakout_level * 0.97`) 시 동일봉 즉시 손절이 `21건(11.9%)` → `12건(6.8%)` / `8건(4.6%)`으로 감소하고 승률이 `23.3%` → `26.7%` / `31.6%`로 상승.
  - 반면 `d_base_pct <= 2.0%` 상한 축소안은 실전 익절 종목 8건 중 5건(`d_base` `2.17%~2.93%`)을 탈락시켜 승률(`23.3% → 19.3%`)과 PF(`0.47 → 0.35`)를 오히려 악화시키므로 기각함.

### 4. 남은 한계 (Limitations)
- 완료 신호 표본(46건)은 소규모 탐색 표본이므로 하위 그룹 및 필터 성과는 탐색적 가설로만 취급하며, 향후 독립 전진 표본(Out-of-Sample) 축적 후 재검증이 필요하다.
- `bars_history/` 365종목 데이터는 현재 시총 상위 유니버스 기준이므로 과거 상장폐지/유니버스 이탈 종목이 제외된 생존·선택 편향을 내포한다.
