## 🔢 대장주 산식 (§4 그대로, 변경 없음)

- 대상: 국내(`KR`) 13개 섹터 대표 ETF의 조회일 공개 상위 구성종목(네이버 `etfAnalysis` → `etfTop10MajorConstituentAssets`). 보통주 코드(`^[0-9]{4}[0-9A-Z]0$`)만, 우선주·ETF·스팩·리츠·현금 제외. **시총 상한 없음**(삼성전자·삼성바이오로직스 등 포함).
- 완료 일봉 120거래일 이상, 평가일 정상 거래(거래량 0 정지봉은 `Halted`로 제외).
- 섹터별 **20일 거래대금 중앙값 상위 5개** → **섹터 대표 ETF 대비 RS20 > 0** 중 최고 1종목(동률: 거래대금 내림차순 → 코드 오름차순).
- 개별 자격: `종가 > SMA60` 및 `종가 − SMA20 ≤ 2×ATR20`.
- 주간 C 후보: `KR` 커버리지 충족·`KODEX 200 ≥ SMA120`·섹터 신규 자격 통과 섹터를 RS20 내림차순 최대 3개, 종목 중복 제외. 산식은 `signals.select_weekly_stock_candidates_c`와 동일하게 재구현했다(`signals.py`는 `is_pit_verified=False` 표를 거부하므로 T-147 해시 보존을 위해 수정하지 않음).
- `US` 개별주는 §4에 따라 미실시(대표 ETF 전용).

## 🖥️ README 2-1) 표시 규칙

- 2번 B 후보가 있으면: 해당 섹터의 대장주. C 자격까지 충족하면 `✅ 대장주 후보` + E1 확인 허용가·이탈 기준선·0.5% 참고 수량. C는 국내 섹터만 순위를 매기므로 B 슬롯 밖 국내 섹터의 C 후보도 같은 표에 추가한다.
- 2번 후보가 0건이면: 관찰 강세(`RS20>0` & `5일 개선>0`) 국내 섹터 중 RS20 상위 최대 3개의 대장주를 **미리보기**로 표시. 확인 허용가·수량은 산출하지 않는다(매수 대상 아님).
