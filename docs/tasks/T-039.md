## 🛠️ 설계 및 구현 세부사항

### 1. 현금 배분 및 주식수 산정 (Equal Slot Cash Allocation)
- 진입 시점의 가용 슬롯: `open_slots = max_positions - len(positions)`
- 슬롯당 할당 현금: `allocated_cash = cash / open_slots`
- 주문 주식 수: `qty = int(allocated_cash // (price * (1 + fee)))`
- **특징**:
  - `max_positions=1`일 때 `open_slots=1`, `allocated_cash=cash`가 되어 기존 수식(`int(cash // (price * (1 + fee)))`)과 완벽히 동일.
  - 다중 포지션 진입 시 현금이 초과 사용되지 않으며, 현금 잔고와 포지션 평가액의 합이 정확히 자산 곡선(Equity curve)과 일치함.

### 2. 불변식 준수
- **동일 종목 중복 진입 방지 (Rule 30)**: 이미 보유 중인 종목에 대해 후속 봉에서 신호가 다시 발생하면 신규 진입하지 않고 무시(`skipped += 1`).
- **미체결 시 소급 선택 금지 (Rule 27)**: 거래량 0 또는 잔고 부족(`qty < 1`)으로 미체결(`no_fill`) 시, 랭킹 하위 종목을 소급하여 대신 채우지 않음.
- **보수적 청산 우선순위 (Rule 29)**: 동일 봉에서 손절선(-5%)과 익절선(+10%)이 동시 접촉하면 손절 우선(`STOP`).

## 🔍 객관적 사실 및 분석 결론

1. **표본 수 한계 극복**:
   - `mp=3`과 `mp=5` 모두 전 구간에서 체결 건수 12~18건을 기록하여, `bias_reporter.py`의 `Trade count < 8` 경고를 충족/해소함.
2. **분산 투자의 실질적 가치 입증**:
   - 하락장(Train)에서 단일 포지션 몰빵은 -26.31%까지 추락했으나, `mp=5`는 -12.02%로 손실을 절반 수준으로 방어함.
   - Validate 및 Test에서도 MDD가 각각 -2.44%, -6.06%로 매우 안정적으로 억제됨.
3. **승률의 강건성(Robustness)**:
   - 단일 포지션의 4건 표본에서 관측된 승률 75%가 우연이 아니었는지에 대한 의구심이 있었으나, `mp=3`(13건 중 10승, 76.9%) 및 `mp=5`(16건 중 12승, 75.0%)로 표본을 3~4배 확대한 뒤에도 **반등/상승 구간 75% 내외의 승률이 그대로 유지**됨.
4. **최적 균형점**:
   - `mp=3`은 Train 하락 방어(-19.13%), Validate 수익 극대화(+20.39%), Test 수익(+16.81%) 사이에서 가장 우수한 밸런스를 제공함.
