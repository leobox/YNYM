# T-097: 루트 README에 T-095·T-096 운영 안내

- **상태**: in_progress
- **담당**: Codex
- **소유 파일**: 루트 `README.md`, 이 문서
- **선행 작업**: T-095, T-096

## 변경 이유

T-095 구현 안내는 `quant-research/README.md`에만 있었고, GitHub 첫 화면인 루트 `README.md`에는 없었다. T-096 안내도 루트에 없었다. 사용자가 두 작업을 함께 표시하도록 지적했다.

## 변경 원칙

- 자동 갱신되는 `MODE2_DAILY`와 `QUANT_DASHBOARD` 마커 **밖**에 짧은 고정 안내를 둔다. 수집기 자동 커밋이 작업 안내를 지우지 않도록 한다.
- 현재 GitHub `main`에서 확인되는 T-095 `explore`와 T-096 저널의 실행 명령, 읽기 전용 성격, EPS의 표준화 SUE 미충족, 데이터 신선도 확인 명령, 상세 작업 문서 링크를 표시한다.
- 제미나이의 추가 T-095 작업은 아직 별도 변경을 확인하지 못했으므로 완료 내용으로 주장하지 않는다. 제미나이 변경이 실제로 병합되면 이 문단을 재검토한다.

## 검증

- 루트 README에서 두 명령과 작업 링크를 확인한다.
- 자동 갱신 마커 시작·종료가 각각 하나씩 유지되는지 확인한다.
- `git diff --check` 및 문서 링크 대상 확인 후 GitHub `main`에 반영한다.
