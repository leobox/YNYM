# 백테스트·체결·계좌 검증

`quant-research` 작업은 루트 기준 `quant-research/AGENTS.md`, `quant-research/docs/rules.md`의 백테스트 절을 먼저 읽는다. 다른 프로젝트에는 그 프로젝트의 전략 가정을 적용한다.

- 입력 데이터의 기간·종목군·공급원·수정주가·원본 버전을 확인한다. 현재 종목군, 상폐 누락, 15시 구간 누락을 편향 없는 데이터로 표시하지 않는다.
- 전체 계산의 prefix와 각 시점에서 자른 입력의 계산을 비교한다. 신호 시점 뒤 정보, 진입봉 최종 거래량·고저, 전체 기간 통계가 후보 선정에 유입되지 않게 한다. 미래 수익 라벨과 신호 계산은 분리한다.
- 다음 관측 봉 가상 시가 진입과 데이터 수신 지연을 구별한다. 선택 후 거래량 0이면 미체결이며 후보 소급 교체를 하지 않는다.
- 같은 봉 손절·익절, 목표 위 시가, 손절 아래 갭, 거래일 만기, 기간 말 청산, 비용·슬리피지의 경계 사례를 검증한다.
- 단일 포지션·정수 주식·잔여 현금, 보유 중 신호 무시, 청산봉 재진입 금지, 부분 익절 현금 재사용 금지와 회계 보존식을 검사한다. 순차 계좌 루프를 벡터화하기 위해 의미를 바꾸지 않는다.
- +10% 도달률/비용 후 수익 거래율/독립 신호 평균/계좌 수익을 별도로 집계한다. 표본 수, 비용, MDD 관측 주기, 기간별 성과, 보유 시간, 무신호 일수를 보고한다.
- CAGR·Sharpe·Profit Factor는 데이터와 기간이 적합할 때만 산출하고 미정의 분모를 처리한다. Profit Factor와 평균 손익비를 혼동하지 않는다.
- 확률적 실험은 seed·환경을 고정한다. 학습·검증·후속 구간, 탐색 조합 수와 사전 채택 기준을 기록한다. 반복 열람 기간을 새 OOS라 하지 않는다. 소수 거래의 100%를 미래 확률로 쓰지 않는다.

변경 위험과 관련된 회귀 테스트를 실행한다. 연구 실행 스크립트를 단위 테스트로 오인해 전체 시장 다운로드나 대규모 튜닝을 시작하지 않는다. 결함은 재현 입력·파일 위치·영향을 제시하고, 실측/근사/스트레스 결과 및 미검증 항목을 구분해 인수인계한다.
