# 🏋️ Gym App (안드로이드 헬스 앱)

개인 운동 기록 및 루틴 관리를 위한 안드로이드 앱 개발 공간입니다.

## 📱 개발 개요
- **타깃 플랫폼**: Android
- **추천 기술 스택**: 
  - Android Native (Kotlin + Jetpack Compose) 또는
  - 크로스플랫폼 (Flutter / React Native)
- **주요 기능 계획**:
  - 운동 루틴 및 세트/반복수 기록
  - 운동별 중량 추이 및 그래프
  - 타이머 및 휴식 시간 알림

## 📁 디렉터리 구성 (추후 프로젝트 초기화 시)
- Android Studio 프로젝트 생성 후 해당 코드를 이 디렉터리에 배치하여 관리할 수 있습니다.
