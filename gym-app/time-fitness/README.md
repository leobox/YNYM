# 타임 피트니스 1.5

갤럭시 Z 폴드6용 운동 캘린더 앱입니다. 기존 RUNG'S GYM과 다른 패키지(`com.timefitness.app`)여서 별도로 설치됩니다. 기존 앱의 기록은 가져오거나 변경하지 않습니다.

## 설치

1. `TimeFitness-1.5.apk`를 휴대폰으로 옮기고 내 파일 앱에서 실행합니다. 기존 타임 피트니스 1.0/1.1은 삭제하지 않고 업데이트합니다.
2. 설치 권한 안내가 나오면 해당 파일 앱의 설치를 허용하고 설치합니다.

## 사용

- 위의 **주 / 월** 버튼으로 캘린더 보기를 변경합니다. 화살표는 이전·다음 기간, **오늘**은 현재 날짜로 이동합니다.
- 날짜를 **한 번 탭**하면 등록한 운동과 무게·횟수·세트가 표시됩니다.
- 이 목록에서 각 운동의 **메모를 입력한 뒤 메모 저장**을 누릅니다.
- 날짜를 탭한 뒤 **운동 추가 / 편집** 버튼을 한 번 누르면 편집 화면이 열립니다. 길게 누르는 편집 동작은 없습니다.
- 운동 구분은 **개인운동(파랑)** 또는 **PT(초록)**입니다.
- **상체 · 하체 · 기타** 중 분류를 선택합니다. 기본 운동 목록은 비어 있습니다. **운동명 추가 → 저장**으로 목록을 등록합니다. 목록의 운동명을 삭제해도 이미 저장한 캘린더 기록은 유지됩니다.
- 운동을 선택하고, **kg · 횟수 · 세트 → 운동 추가**로 추가합니다. 마지막에 **저장**을 누릅니다.
- 편집 목록에서 운동을 누르면 수정할 수 있고, `×`를 누르면 확인 후 삭제합니다. 메모는 운동 편집 화면에서 수정하지 않습니다.
- 주간 칸은 운동명을 최대 5개까지 보여 주고 나머지는 개수로 표시합니다. 월간은 운동 구분과 총 개수로 요약합니다.

시작 화면과 앱 아이콘은 제공된 이미지를 사용합니다. 소리는 없습니다. 설정에는 백업과 가져오기만 있습니다.

## 백업과 가져오기

- **설정 → 전체 백업**: 휴대폰의 시스템 파일 저장 화면에서 저장 위치를 선택합니다. 모든 저장된 운동 기록, 개인운동/PT 구분, kg·횟수·세트, 운동별 메모, 분류별 운동명을 JSON 파일 하나에 저장합니다. 아직 저장 버튼을 누르지 않은 입력값은 포함하지 않습니다.
- **설정 → 가져오기**: 시스템 파일 선택 화면에서 백업을 고릅니다. 날짜 수·운동 수·운동명 수를 확인하고 **가져오기**를 누르면 현재 전체 데이터를 교체합니다. 취소하거나 잘못된 파일을 고르면 기존 데이터는 바뀌지 않습니다.
- 휴대폰을 바꾸기 전에 백업을 만들고 파일을 새 휴대폰으로 옮겨 가져옵니다. 앱 삭제 후 재설치할 때도 같은 방식으로 복원합니다.
- 1.0의 앱 내부 기록은 업데이트 시 유지됩니다. 운동 목록은 새 기능이므로 빈 상태로 시작합니다. 기존 기록에 있는 운동명도 기록의 운동명을 선택하여 수정할 수 있습니다.
- 백업 형식은 `time-fitness-backup` 버전 1입니다. 이전 버전의 원본 기록 JSON(`version:1`, `days`)도 가져올 수 있습니다. 파일 크기 상한은 32MB입니다.

## 저장과 폴드 화면

인터넷·로그인·서버를 사용하지 않습니다. 안드로이드 SharedPreferences에 JSON으로 저장하며, 새 설치는 예시 기록 없이 시작합니다. 앱 삭제 또는 앱 데이터 삭제 시 기록도 지워집니다.

접힘 화면은 주간 날짜를 세로로, 펼침 화면은 4열로 배치합니다. 넓은 화면은 7열로 표시합니다. 화면 크기 변경 시 Activity를 재시작하지 않으므로 작성 중인 입력값이 유지됩니다. 실제 화면 배치는 휴대폰의 화면 확대 설정에 따라 달라집니다.

## 검증

- SDK 34로 빌드, 최소 Android 6.0 / API 23, 타깃 API 34.
- APK v1/v2/v3 서명 및 ZIP 정렬 검증 완료.
- Chromium에서 운동명 추가·삭제, 기본 목록 없음, 직접 입력, 메모 수동 저장 및 재실행 복원, 삭제한 운동명의 과거 기록 편집, 화면 전환 중 입력값 유지, 전체 백업 파일 저장·가져오기, 잘못된 파일 거절 및 저장 실패 시 원복을 확인했습니다.
- 1.0 데이터 읽기 및 안드로이드 브리지 인터페이스의 성공·취소·실패 경로를 모의 검사했습니다. 1.0과 1.1의 서명 인증서가 같습니다.
- 320 / 372 / 690 / 850px 폭의 화면 확인.
- 실제 안드로이드 기기 설치·실행 및 시스템 파일 선택 화면 검증은 연결된 기기가 없어 수행하지 않았습니다.

## 개발 / 다시 빌드

Java 11과 Python 3가 필요합니다. SDK 다운로드는 Google의 공식 배포본을 사용하며 공개 체크섬으로 확인합니다.

```powershell
python tools/setup_android.py
python time-fitness/build.py
```

결과는 상위 폴더의 `TimeFitness-1.5.apk`입니다. `assets/index.html`, `assets/app.css`, `assets/management.css`, `assets/app.js`가 앱 화면이며 `assets/data.js`가 백업 검증과 데이터 호환을 담당합니다. `java/com/timefitness/app/MainActivity.java`는 로컬 저장, 시스템 파일 선택, 안드로이드 셸입니다.

`time-fitness/signing/`에 최초 생성된 서명 키와 암호 설정이 있습니다. 업데이트 APK를 기존 설치 위에 설치하려면 이 폴더를 보관하고 같은 키로 빌드해야 합니다. 배포용 소스 ZIP에는 개인 서명 키를 넣지 않았습니다. 업데이트 시 `AndroidManifest.xml`의 버전 코드도 올립니다.

화면 테스트는 `playwright-core` 및 Chromium 설치 후 `node time-fitness/test-1.5.cjs`로 실행합니다. 별도 경로에 설치한 경우 두 번째 인자로 `playwright-core` 모듈 경로를 전달할 수 있습니다.

## 1.2 변경사항

- 운동명 선택 후 수정 → 저장으로 이름을 변경합니다. 같은 분류의 동일 운동명에 해당하는 저장 기록도 이름이 변경되며, 무게·횟수·세트·메모는 유지됩니다.
- 메모 박스 위의 운동 메모 글자를 제거했습니다.
- 직접 입력 분류를 제거했습니다. 이전 직접 입력 기록은 기타로 호환하며 운동명과 기록은 유지합니다.


## 1.3 변경사항

- 날짜 창 제목을 날짜와 요일로 통일했습니다.
- 주간·월간 캘린더가 일요일부터 시작합니다.
- 운동 추가 / 편집 버튼은 한 번 눌러 엽니다.
- 창 밖을 누르면 닫힙니다. 저장하지 않은 메모나 편집 내용이 있으면 취소 여부를 확인합니다.


## 1.4 변경사항

- 편집 화면의 운동 분류 기본값은 전체 보기입니다. 모든 분류의 운동명이 가나다순으로 표시되며 각 분류에서도 가나다순으로 정렬합니다.
- 전체 보기에서 이름이 같은 운동은 분류를 함께 표시합니다. 운동명 추가 시 저장할 분류를 선택합니다.
- 날짜를 열면 각 운동의 메모는 접혀 있습니다. ◀ 버튼을 누르면 ▼로 바뀌고 메모가 펼쳐집니다. 접었다 펼쳐도 입력은 유지되며 메모 저장 방식은 동일합니다.


## 1.5 변경사항

메모가 있으면 접기·펼치기 화살표를 운동 수치와 같은 하늘색으로 표시합니다. 빈 메모나 공백만 있는 메모는 기존 회색을 유지합니다. 입력·삭제 시 색상이 갱신되며 저장 방식은 동일합니다.
