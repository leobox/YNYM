# AGENTS.md — 🏋️ Gym App (헬스 앱 도메인 규칙)

안드로이드 헬스/피트니스 기록 애플리케이션 개발 시 모든 AI 에이전트가 준수해야 하는 모바일 도메인 규칙입니다.

---

## 📱 사용자 경험 (Gym UX) 불변식

1. **운동 환경 친화적 UI (한 손 조작 & 시인성)**:
   - 헬스장 환경(운동 기구 사용 중, 땀이 묻은 손, 거친 호흡)을 고려하여 모든 핵심 버튼의 터치 타깃은 최소 48dp 이상으로 큼직하게 설계합니다.
   - 어두운 실내 환경 및 아몰레드 배터리 절약을 위해 **다크 모드(Dark Mode)**를 기본 테마로 지원합니다.
   - 복잡한 텍스트 입력 대신 숫자 패드나 원터치 증감 버튼(+1kg, +5kg, +1회)을 제공합니다.

---

## 💾 오프라인 퍼스트 (Offline-First) 및 안정성

2. **완전한 오프라인 독립성**:
   - 헬스장 지하나 통신 음영 지역에서도 모든 운동 루틴 열람, 세트 기록, 타이머 작동이 네트워크 없이 100% 완벽히 동작해야 합니다.
   - 모든 사용자 입력은 즉시 로컬 데이터베이스(Room / SQLite)에 저장되어야 합니다.

3. **운동 세션 상태 보존 (Zero Data Loss)**:
   - 운동 중 음악 앱 전환, 카메라 사용, 전화 수신 등으로 앱이 백그라운드로 전환되거나 OS에 의해 프로세스가 재시작되어도, 현재 진행 중이던 세트 및 휴식 타이머 상태가 유실되지 않아야 합니다.

4. **데이터 단위 및 유효성 검증**:
   - 중량: kg 단위를 기본으로 하며 0.5kg 단위 소수점 지원, 음수 입력 절대 불가.
   - 횟수(Reps): 0 이상의 정수.
   - 세트 완료 시점: KST 기준 타임스탬프를 자동 기록하여 휴식 시간 계산 및 일자별 통계에 반영.
