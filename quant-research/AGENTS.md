# Quant Research — 모든 AI의 공통 작업 규칙

Codex, Claude Code, Gemini CLI, Antigravity 및 다른 AI가 같은 기준으로 작업한다.
상위 [AGENTS.md](../AGENTS.md)의 협업 절차와 이 문서를 함께 읽는다.

## 기준과 현재 상태

- 제품 요구와 기존 실험의 기준은 [설계문서.md](설계문서.md). 상세 불변식은 [docs/rules.md](docs/rules.md).
- 문서의 `agent/` 파일은 이전 프로젝트 `D:\DEPO_M`의 자료다. 코드 이전·검증 상태는 루트 백로그 CLI와 `docs/tasks/T-007.md`에서 확인한다. 설정 구성 완료를 운영 코드 재현 완료로 취급하지 않는다.
- 대상은 모바일 Colab 한국 주식 60분봉 패턴 스캐너 및 연구 재현이다. `quant-collector`의 샘플 수집기를 완성된 스캐너로 취급하지 않는다.
- 이전 코드·데이터의 존재와 파일 크기를 확인하고 별도 작업으로 옮긴다. 문서에 없는 점수 공식을 임의로 복원하지 않는다.
- 안정적인 +10%는 목표이며 검증된 기능이 아니다. 95%를 맞추기 위한 튜닝을 하지 않는다.

## 항상 지킬 것

1. 실제 주문·계좌 연동 API를 작성하거나 호출하지 않는다. 가상 체결·손익 계산은 허용한다. 주석이나 `buy_price` 같은 변수명만으로 주문 로직이라 판정하지 않는다.
2. 완료봉과 그 시점에 수신 가능한 정보만으로 신호를 계산한다. 다음 봉 확인 전에는 최종 후보가 아니다.
3. 운영 기준과 미채택 연구 전략을 분리한다. 조건 변경은 고정된 후속 구간 검증과 채택 근거를 기록한다.
4. 최종 후보는 최대 5개, 0개 허용. 관찰표를 미달 종목으로 채우지 않는다. 현재가 보조 조회는 자격·순위를 바꾸지 않는다.
5. 원본·조회 시각·종목군·설정·코드 버전·결과를 한 실행 단위로 추적한다. 실패값을 0이나 과거 현재가로 위장하지 않는다.
6. 사용자 요청 없이 알림 전송·배포·계좌 연결을 추가하지 않는다. 상시 PC, C#, DB, 차트 프레임워크를 이식하지 않는다.

## 착수와 인수인계

- 워크스페이스 루트에서 `node tools/backlog.mjs get <id>`로 범위를 확인한 뒤 `set <id> in_progress`로 착수한다. `backlog.json`은 CLI로만 변경한다.
- `docs/tasks/<id>.md`에 담당 AI, 수정 파일, 가정, 검증 명령·결과, 남은 한계를 기록한다. 다른 AI의 작업을 덮어쓰지 않는다. 병렬 편집은 별도 worktree 또는 명확한 파일 소유 범위로 분리한다.
- 로컬 규칙과 사용자의 명시적 변경 요구가 충돌하면 변경 근거를 기록하고 규칙도 맞춘다. 이미 승인된 범위에 재승인을 요구하지 않는다.
- 관련 스킬은 루트 `.agents/skills/`의 원본을 읽는다. 자동 발견이 없는 AI도 같은 파일을 직접 읽으면 된다.

| 작업 | 스킬 |
|---|---|
| 완료봉, 데이터 공급원, 원본 이전·재현 | `quant-data-provenance` |
| 기본 패턴, 돌파·유지, 후보 선정 | `quant-pattern-scanner` |
| 백테스트, 체결, 계좌, 성과 보고 | `quant-backtest-validator` |
| Colab 단일 셀, 노트북 동기화, 모바일 표 | `quant-colab-release` |
| 작업 기록 / 완료 전 검토 | `backlog-manager` / `adversarial-reviewer` |

## 완료 기준

- 루트에서 `python tools/ai/quant_guard.py` 및 변경에 맞는 기능 테스트를 실행한다. 훅 통과만으로 전략 검증 완료라고 하지 않는다.
- 시점 변경은 prefix 불변성, 체결 변경은 손절·익절 동시 접촉/갭/회계 보존, 화면 변경은 무후보/시세 실패/관찰 구분, 배포본 변경은 Python·노트북 일치를 검증한다.
- `agent/test_stable_pullback.py` 같은 연구 실행 파일을 단위 테스트로 자동 실행하지 않는다. 네트워크 없는 테스트를 기본으로 사용한다.
- 원본 코드가 없거나 시장 데이터 검증을 못 했다면 미검증으로 보고한다. 완료 보고에 변경·검증·남은 한계를 포함한다.
- AI별 연결과 훅의 보장 범위는 [협업 설정 안내](../docs/ai-setup.md)를 참조한다.
