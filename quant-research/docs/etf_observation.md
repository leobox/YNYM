# ETF 상승 초입 관찰 (연금계좌 매수 가능)

국내 상장 ETF 중 실제 **연금저축펀드·퇴직연금(DC/IRP) 계좌에서 매수 가능한 투자형 ETF**를 개별주 최종 상승 초입 화면과 동일한 2트랙(`20일 돌파 확정`, `20일 수축 돌파임박`)으로 살펴보는 별도 관찰 기능이다. 해외주식에 투자하는 국내 상장 ETF와 실물 금현물(`KRX금현물`) ETF를 포함한다. 주식 `T-131` 엔진이나 운영 후보의 조건을 바꾸지 않는다.

- `ETF 상승 초입 · 20일 돌파 확정`: 종가가 직전 20일 고가 이상.
- `ETF 상승 초입 · 20일 수축 돌파임박`: 같은 추세·유동성·수축·거래량 조건을 통과했지만 종가가 직전 20일 고점 아래에서 돌파를 준비 중.
- 각 표 최대 5개. 미달 종목으로 빈자리를 채우지 않는다. 표의 순서는 상승 확률이 아니다.
- **연금계좌 적격 및 파킹형 제외 (`T-133` 보완):**
  - 연금계좌 매수 불가 **레버리지·인버스(`Tab 3`)** 제외.
  - 퇴직연금(DC/IRP) 파생상품 위험평가액 한도(40%)로 매수가 제한되는 **선물·원자재파생·합성형 ETF(`선물`, `WTI`, `합성` 등 — 단 실물 `KRX금현물`은 허용)** 제외.
  - 일간 이자 누적으로 차트가 계단식 우상향하여 20일 고점 돌파를 독식하던 **CD금리·KOFR·SOFR·머니마켓(MMF)·단기채·채권혼합(`Tab 6·7`)** 파킹형 제외.

## 실행

워크스페이스 루트에서:

```powershell
python -B quant-research/scripts/run_etf_observation.py --readme README.md
python -m pytest quant-research/tests/test_etf_observer.py -q
```

기본 범위는 네이버 ETF 목록에서 레버리지·인버스, 선물·합성 파생형, 금리·채권 파킹형을 제외한 **연금저축·퇴직연금(DC/IRP) 매수 가능 투자형 ETF 가격×거래량 상위 100개**다. 현재 목록 스냅샷으로 고르는 것이며 과거 시점의 종목군이 아니다. `--limit`은 1~200, `--include-leveraged`는 명시적으로 해당 상품을 포함한다.

`--render-only <저장 JSON> --readme README.md`는 해당 실행의 표를 다시 표시한다. 새로 조회한 자료가 아니며 원래 기준일과 조회 시각을 유지한다.

## 데이터와 판정

- 공개 조회: `https://finance.naver.com/api/sise/etfItemList.nhn`, `https://fchart.stock.naver.com/sise.nhn`. 주문·계좌 API는 없다.
- 260개 일봉 요청. 한국시간 16시 이전에는 당일 봉을 제외한다. 최소 125개 최근 공통 거래일의 유한 OHLCV가 필요하다. 조회·파싱 실패, 중복 날짜, 종목 불일치, 가격 정합성, 결측을 검사한다.
- 같은 최종 날짜를 가진 ETF가 선택 목록의 90% 미만이면 후보 산출을 보류한다. 날짜 최빈값을 쓰되 동률이면 최신 날짜를 택한다. 7일 초과 자료는 오래된 자료로 표시한다. 별도 거래소 휴장 달력과 실시간 공급 지연 판별은 구현하지 않았으므로 표의 **완료 일봉 날짜**를 확인해야 한다.
- 추세: 종가 ≥ SMA20, 그리고 종가 ≥ SMA60 또는 SMA20 ≥ SMA60.
- 대금: 최근 20일 종가×거래량 중앙값 ≥ 5억원, 평가일 거래량 > 0.
- 비과열: 5번째 전 관측 종가 / 60번째 전 관측 종가 − 1 ≤ 25%, 종가 / SMA60 ≤ 1.18.
- 수축: 평가일을 뺀 직전 20봉 고저폭 / 직전 60봉 고저폭 ≤ 0.85, 직전 20봉 고저폭 / 종가 ≤ 25%.
- 수급: 최근 5봉 거래량 중앙값 / 그 이전 20봉 중앙값 ≥ 1.2 또는 평가일 거래량 / 같은 기준 ≥ 1.35, CMF20 ≥ −0.05.
- 각 표 안에서 거래량·폭 수축·범위 내 위치·CMF의 백분위 점수를 35/25/20/20으로 합친다. 동점은 대금 내림차순, 코드 오름차순이다. 서로 다른 표의 점수를 직접 비교하지 않는다.

125봉 검사를 통과한 관찰군의 SMA60 위 비율은 참고값이며 국내 주식 시장 국면 판정이나 후보 차단에 쓰지 않는다. 채권·금리·해외자산 ETF를 섞은 비율이므로 주식 시장의 상승 비율로 읽지 않는다.

## 기록과 자동 갱신 설정

`data/etf_observation/latest.md`가 표, `latest.json`과 `runs/<실행ID>.json`이 실행 결과다. `raw/<실행ID>/`에 압축 원본과 실행 코드 복사본을 보존한다. 해시, 조회 시각, 종목군, 공급원, 데이터 품질, 설정, 라이브러리 버전과 Git 상태를 기록한다. 새 실행은 이전 원본을 덮어쓰지 않는다.

`.github/workflows/etf-observation.yml`은 평일 20:35 KST 및 수동 실행을 정의한다. 배포되어 실행되면 원본을 Actions artifact로 30일 보존하고 결과·README를 기록한다. 로컬 파일 작성만으로 원격 예약 실행이 활성화되지는 않는다. README의 `ETF_OBSERVATION` 블록만 갱신한다.

ETF별 수정주가, 분배금 포함 총수익, NAV 괴리와 ETF 전략 수익성은 검증하지 않았다. 기존 상승초입식의 참고 조건을 적용했으며, 주식 백테스트 결과를 ETF 성과로 옮겨 주장하지 않는다.
