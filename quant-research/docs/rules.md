# 모바일 패턴 스캐너의 연구·운영 불변식

근거: [설계문서](../설계문서.md) §§4–8, 10–12. 아래는 개발 수용 기준이며 현재 구현 완료 목록이 아니다.

## 데이터와 시각

- Asia/Seoul로 통일하되 봉 시작/종료, 데이터 수신, 후보 발견, 보조 시세, 실제 체결 시각은 별도 필드로 보존한다. 실제 체결이 없으면 값을 만들지 않는다.
- 정규 봉 시작, 중복 인덱스, 미완료봉, OHLC 정합성, 음수 거래량, NaN/Inf를 검증한다. 장 종료 뒤 거래량 0·고가=저가인 15시 표시용 봉을 제외한다. 모든 무거래 봉을 삭제하는 규칙으로 확대하지 않는다.
- 실시간 패턴 최소 120봉. 최근 7일 조건만으로 장중 최신성을 보장하지 않는다. 휴장·지연·실패·무후보를 구분한다.
- Yahoo 14시 시작 봉 종가는 15:30 공식 종가가 아니다. 15:00~15:30 누락, 수정주가·기업행사·시장 불일치를 표시한다. 네이버 현재가 한 번으로 다음 봉 저가/종가를 복원하지 않는다.
- 요청마다 유한 timeout, 제한된 재시도/backoff, 호출 수를 명시한다. 후보 코드 중복 제거 후 basic/integration 각각 조회하고 후보가 없으면 보조 조회 0회. 비공식 엔드포인트의 이용 조건·지연·단위는 채택 시 확인한다.
- 실행별 manifest에 run_id, fetched_at, 종목군 기준일/출처, 공급원/시장/수정주가/단위, 설정, 코드 버전과 dirty 여부, 파일 해시·행 수, 결측/실패, 과거 종목군·상폐 포함 여부를 기록한다. 재조회로 과거 원본을 덮어쓰지 않는다.
- 재시도 중복과 별도 실행 기록을 구분한다. 동일 실행 저장은 원자적·멱등적으로 처리하고 다른 실행은 별도 ID로 보존한다. 원본/실제 거래 기록의 저장·공개 정책을 정한 후 추적한다. 비밀키는 이식하지 않는다.

## 운영 패턴 — 임의 변경 금지

- 기본 패턴: SMA12 최근 3봉 기울기 양수, SMA26 최근 3봉 기울기가 3봉 전보다 개선, 종가가 두 선 위, 최근 3봉/직전 20봉 분당 거래량 비율 ≥1, 직전 20봉에 SMA12<SMA26 존재, 가격 ≥2,000원, 유한 점수. 세부 점수는 이전 소스 확인이 필요하다.
- 돌파: 두 선이 각각 3봉 전보다 높음, 종가가 두 선 및 직전 6봉 최고가를 초과, 양봉, (종가−저가)/(고가−저가) ≥0.7, SMA26 이격 ≤4 ATR. 분모 0은 미충족/미계산으로 다룬다.
- 돌파봉 추정 대금=종가×거래량 ≥10억원. 현재 봉을 뺀 과거 같은 시간대 최대 20표본의 중앙값 대비 ≥2배, 최소 5표본. 추정 대금과 실제 체결 대금을 구분한다.
- 바로 다음 완료봉: 저가 ≥돌파선, 종가 ≥돌파봉 종가, 두 선 상승·가격이 두 선 위·이격 ≤4 ATR, 기본 패턴도 충족. 확인봉에 거래대금 2배를 재요구하지 않는다.
- 최종: 점수 내림차순·코드 오름차순 최대 5개. 관찰: 현재 완료봉이 기본 패턴·돌파·대금을 통과하고 다음 봉 마감만 대기. 최종과 중복 없음, 관찰 5개 제한은 기존 조건이 아니다.
- RSI는 참고값, +3%/+5% 이격은 참고 구간이다. 미채택 MA60/눌림/이격 필터를 운영 게이트로 추가하지 않는다.

## 백테스트와 계좌

- 전체 데이터의 앞부분 결과와 해당 시점까지만 넣은 결과를 비교하는 prefix 불변성 테스트로 미래정보 누출을 검증한다. `shift(1)` 한 줄만으로 통과 판정하지 않는다.
- 다음 관측 봉 시가에 가상 진입. 후보 선정에 진입봉 최종 거래량·고가·저가를 사용하지 않는다. 선정 뒤 거래량 0이면 미체결이고 다른 후보를 소급 선택하지 않는다.
- 기준 시나리오: +10% 익절, −5% 손절, 최대 5거래일, 초기 현금 100만원, 단일 포지션·정수 주식·잔여 현금, 편도 비용 0.175% 가정. 실제 세율·수수료 검증값으로 표현하지 않는다.
- 같은 봉 손절·익절은 손절 우선. 다만 시가가 목표 이상이면 목표 지정가 체결, 손절 아래 갭은 시가 청산. 상시 감시 가정과 사용자 수동 확인 시나리오를 분리한다.
- 보유 중 신호 무시, 청산봉 즉시 재진입 금지, 부분 익절 현금은 전량 청산 전 재사용 금지. 동점 선택도 결정적으로 처리한다.
- 기간 말 잔여 보유 청산, 비용/부분청산 원장, 비보유 시 시작 현금+누적 순실현손익=종료 현금, 보유 시 현금+평가액=자산을 검증한다. 독립 신호와 계좌 성과를 섞지 않는다.
- 최신 연구 기준은 11시 고정 탐색. 데이터 수신·판단 지연과 실제 체결 가능 가격을 별도 시나리오로 둔다. 09/12/15시 실험 및 60분 지연 결과를 우월성으로 일반화하지 않는다.
- 기간과 설정을 사전 고정하고 학습/검증/후속 구간을 구분한다. 반복 열람한 기간은 새로운 OOS가 아니다. 확률적 실험은 seed와 라이브러리 버전을 기록한다.
- 현재 고정 종목군의 선택·생존편향, 상폐 누락, 15시 구간 누락, 표본 수와 겹치는 거래를 보고한다. 편향을 공지하는 것만으로 해결됐다고 하지 않는다.
- +10% 도달률, 비용 후 수익 거래율, 독립 신호 평균 수익, 계좌 수익을 각각 정의한다. 거래 수·기간별 성과·MDD·손실 꼬리·보유 시간·기회비용·무신호 일수도 보고한다. MDD 관측 단위는 시간봉이다.
- CAGR/Sharpe/Profit Factor는 데이터·기간이 적합할 때만 가정과 함께 제시한다. 짧은 표본 연율화를 기대수익으로 홍보하지 않는다. Profit Factor는 총이익/총손실 절댓값이며 평균 이익/평균 손실인 손익비와 다르다. 0분모는 미정의로 표시한다.
- 회계 상태 전이는 명시적 순차 루프를 허용한다. 지표 계산은 가능한 벡터화하되 성능 때문에 체결 순서의 정확성을 희생하지 않는다.

## Colab과 모바일

- 단일 셀·로컬 프로젝트 import 없이 실행, 다크테마 종목별 2열 표, 차트 없음. 배포 Python과 노트북 코드 셀의 동기화를 검사한다.
- 초록 ‘패턴 조건 충족’, 노랑 ‘다음 봉 마감 대기’. 점수는 확률이 아니고 돌파선은 추천 매수가가 아니다. ‘매수 검토’ 문구를 ‘패턴 충족’으로 정리한다.
- 가격 차이는 색상+부호/문구로 표시. 현재가·돌파선·돌파 종가·+3/+5% 비교 가격·당일 고가·원/% 차이를 같은 기준과 단위로 계산한다.
- 당일 누적 대금과 돌파봉 추정 대금, 시세 시각과 패턴 시각을 구별한다. 별도 HTTP 요청은 동시 스냅샷이 아니며 고가 발생 시각을 추정하지 않는다.
- 시세 실패는 미제공, 패턴 결과 유지. 실행마다 universe/scores/top5/watch와 manifest를 기록하고 Colab 런타임 초기화 시 유실 가능성을 안내한다.
- Actions 자동화는 후속 과제. 이 저장소는 다중 프로젝트 구조이므로 루트 `.github/workflows`와 working-directory를 확인한다. 실제 배포 전에는 ‘운영 중’이라고 쓰지 않는다.
