# AGENTS.md — ⏱️ Quant Collector (데이터 수집·운영 규칙)

GitHub Actions 기반 1시간 주기 자동 실행 및 모바일 수동 실행 데이터 수집기 개발 시 모든 AI 에이전트가 준수해야 하는 운영/안전 규칙입니다.

---

## 🚨 최상위 안전 불변식 (Safety First)

1. **실거래 / 주문 / 매수·매도 API 절대 작성 금지**:
   - 본 프로젝트의 목적은 오직 **시세 데이터 관측 및 기록**입니다.
   - 주문(Order), 매수(Buy), 매도(Sell), 입출금 등 금융 자산의 거래를 유발하는 어떠한 로직이나 라이브러리도 추가하거나 호출하지 않습니다.
   - 코드 검증 시 주문 관련 키워드가 발견되면 즉시 반려 대상입니다.

---

## ⚙️ 실행 및 데이터 불변식

2. **멱등성 (Idempotency) 보장**:
   - 네트워크 재시도나 수동 재실행으로 인해 동일한 시간대에 스크립트가 여러 번 실행되더라도, 데이터가 중복 기록되거나 손상되지 않도록 타임스탬프 기준 중복 제거 또는 upsert 로직을 적용합니다.

3. **장애 회복력 (Resilience & Timeout)**:
   - 외부 시세 API 호출 시 반드시 타임아웃(최대 10초)을 설정합니다.
   - 일시적 네트워크 에러 발생 시 최대 3회의 Exponential Backoff 재시도를 수행하고, 최종 실패 시에도 상세 에러 로그를 남겨 크래시를 방지합니다.

4. **GitHub Actions 경량화 및 실행 시간 제한**:
   - 불필요한 무거운 패키지 설치를 피하고, 1회 실행 소요 시간이 2분을 넘지 않도록 최적화합니다.

5. **모바일 브라우저 친화적 트리거 유지**:
   - `.github/workflows/` 내 모든 워크플로에는 `workflow_dispatch`가 반드시 선언되어 있어야 하며, 스마트폰 웹 브라우저에서 버튼 하나로 즉시 수동 실행할 수 있어야 합니다.

6. **비밀키 및 토큰 보안**:
   - API Key나 비밀 정보는 절대로 소스코드에 하드코딩하지 않으며, 환경변수(`os.environ`) 및 GitHub Secrets를 통해서만 주입받습니다.
